Goal is to give an introductory talk about R software and ecosystem, and how it can be useful to produce data products such as reports with tables and visualisations.
In particular, I will show how to use R to "reproduce" some elements of the the AITI ICT Survey Report 2022.

The format will be lecture style with hands-on "follow along" (code will be provided). 
There will be two teaching assistants on hand to help out with any questions.
Everyone should bring their own laptop with R and RStudio installed.

No prior knowledge of R is required.
